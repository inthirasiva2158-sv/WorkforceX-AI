# WorkforceX AI

### Right Person. Right Task. Right Time.

WorkforceX AI is an AI-powered workforce task allocation system that helps organizations dynamically assign tasks to employees based on skills, workload, availability, and task priority.

## 🚀 Features

* 👥 Workforce management
* 📋 Smart task allocation
* 🤖 AI-powered allocation recommendations
* ⚡ Dynamic task reallocation
* 🚨 Employee unavailability handling
* 📊 Workforce and task analytics
* 💡 Explainable AI decisions
* 🔥 Chaos Mode for real-time disruption simulation
* 📱 Responsive dashboard

## 🎯 Problem

When an employee becomes unavailable, managers often need to manually identify who should take over their tasks. This can cause delays, workload imbalance, and inefficient resource allocation.

WorkforceX AI automates this process by dynamically reallocating tasks to suitable employees.

## 💡 Solution

The system analyzes:

* Employee skills
* Current workload
* Availability
* Task priority
* Task requirements

It then recommends suitable task assignments and explains why a task was reassigned.
